# 1. Общее назначение системы

[← Назад к оглавлению](index.md)

## Назначение

**VTM (Virtual Turing Machine)** — визуальная среда разработки и исполнения программ на машине Тьюринга. Приложение предназначено для:

- обучения теории формальных вычислений и моделей машин Тьюринга;
- визуального конструирования программ в виде диаграмм состояний;
- автоматической проверки решения учебных задач (упражнений);
- экспорта моделей в текстовые и графические форматы для отчётов и публикаций.

## Функциональные требования

| Код | Требование |
|-----|-----------|
| F-01 | Создание и редактирование проекта с произвольным конечным алфавитом и набором именованных машин. |
| F-02 | Визуальное редактирование диаграммы состояний: добавление, перемещение, удаление узлов и связей. |
| F-03 | Поддержка композитных (вложенных) машин и их повторного использования внутри других машин. |
| F-04 | Сохранение/загрузка проекта в собственном бинарном формате `.jdtp`. |
| F-05 | Совместимость с историческим форматом узлов (v1). |
| F-06 | Пошаговое и непрерывное исполнение программы с подсветкой текущего состояния. |
| F-07 | Бесконечная двусторонняя лента символов с автоматическим расширением. |
| F-08 | Проверка корректности диаграммы (старт, финиш, входящие/исходящие переходы, покрытие алфавита, дубликаты). |
| F-09 | Режим упражнений: загрузка тестов из встроенного XML, автоматическая проверка результата. |
| F-10 | Экспорт диаграммы в PNG. |
| F-11 | Экспорт программы в нотацию «четвёрок» (текст). |
| F-12 | Экспорт диаграммы в PlantUML State Machine (`.puml`). |
| F-13 | Undo/Redo для редактора. |
| F-14 | Масштабирование диаграммы (зум). |

## Нефункциональные требования

| Код | Требование |
|-----|-----------|
| NF-01 | Кросс-платформенность (Windows, macOS, Linux, Android, iOS) с единой кодовой базой на Qt. |
| NF-02 | Сборка через qmake (`.pro`) и CMake. |
| NF-03 | C++17, без сторонних библиотек кроме Qt. |
| NF-04 | Ядро (`vtm_core`) отделено от UI и покрыто unit-тестами (Qt Test). |
| NF-05 | Стабильная сериализация: открытие проектов, созданных в предыдущих версиях. |
| NF-06 | Material-тема UI с централизованной палитрой (`VmtTheme`). |
| NF-07 | Интерактивная отрисовка: перерисовка локальных областей, без перестроения всей сцены. |
| NF-08 | Локализация интерфейса упражнений (русский/английский). |

## Стек технологий

- **Язык:** C++17.
- **GUI/инфраструктура:** Qt Widgets, QPainter, QFileDialog, QDataStream, QXmlStreamReader, Qt Test.
- **Сборка:** qmake (`VirtualTuringMachine.pro`), CMake (`CMakeLists.txt`, опция `BUILD_TESTS`).
- **Архитектура:** ядро `vtm_core` (статическая библиотека) + исполняемый `VTM`.
